# 🛒 E-Commerce Store — متجر إلكتروني لقطع غيار السيارات

مشروع متجر إلكتروني كامل لبيع قطع غيار السيارات، يحتوي على واجهة مستخدم، لوحة تحكم للمدير، نظام تسجيل دخول، إدارة منتجات، إدارة مستخدمين، وسلة مشتريات.

---

## 🚀 المميزات

- تسجيل دخول المستخدمين
- لوحة تحكم للمدير (Admin Dashboard)
- إدارة المنتجات (إضافة – تعديل – حذف)
- إدارة المستخدمين
- إدارة الطلبات
- سلة مشتريات متكاملة
- ربط الواجهة الأمامية بالباك‑اند باستخدام API
- قاعدة بيانات MongoDB

---

## 🧩 التقنيات المستخدمة

### **Backend**
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- Middleware (Auth + Admin)

### **Frontend**
- React + Vite
- React Router
- Axios
- Context API
